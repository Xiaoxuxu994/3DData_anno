# v1.3 管线架构

目标：把野外视频（12 s 片段）变成可用于 3D 基模训练的伪标签：每帧相机内参 K、位姿 c2w、米制深度和置信度。配置以 `configs/pipeline_v13.yaml` 为准（原文件 `outputs/evolution/pipeline_best.yaml`）。

```
视频 ─▶ ① 筛选 ─▶ ② 打标 ─▶ ③ 自校验（质检）─▶ ④ 人工抽检 ─▶ 训练数据
        规则+VLM      ViPE K → Pi3X     跨模型核对 + 旗标      按 QC 分数排序抽看
        切镜切分       尺度对齐 ViPE
```

## ① 筛选（`filter/`）

| 步骤 | 工具 | 拒绝条件 |
|---|---|---|
| 切镜 | TransNetV2 + ffmpeg 场景分数 | 有切镜 → 按镜头切开，保留 ≥ 6 s 的镜头，每个镜头重新走全部步骤（E2，可用帧 +15%） |
| 亮度 / 模糊 / 过曝 | 规则 | 太暗、太糊、过曝 |
| 字幕文字 | PaddleOCR | 大面积文字叠加 |
| 运动 | RAFT 光流 | 相机静止（无视差）、动态过强 |
| 镜头 | GeoCalib（12 帧） | 鱼眼、变焦 |
| 语义 | Qwen3-VL-32B（12 帧，vLLM） | 非实拍、画中画、剪辑等 |

任一步拒绝即拒绝。下游验证：通过片段打标失败率 19.3%，被拒片段 44.0%。

## ② 打标（`evolution/` 中的 v1.3 组件，入口见 `pipeline/`）

1. **内参 K**：用 ViPE（BA）估计。门控：ViPE 的 HFOV 不在 [25°, 130°] 时，改用 GeoCalib、Pi3X（只给图像）、DA3 三者 HFOV 的中位数（E1a）。
2. **位姿 + 深度**：Pi3X 以 K 为条件，一次前向得到位姿、深度、置信度（E1b）。
3. **米制尺度**：k = √(k_depth × k_traj)；k_depth = ViPE 深度中位数 / Pi3X 深度中位数，k_traj = Pi3X → ViPE 相机中心的 Sim3 尺度（E1c、E3b）。
4. **运行方式**：ViPE 常驻进程，每张 H200 两个并发；室内 / 慢速类别隔帧（E6）。

A 组（51 段有真值）对比 ViPE 单独打标：点云 F@5cm 0.49 → 0.81，g20 EPE 11.2 → 7.03 px，米制 AbsRel 0.114 → 0.069；尺度失败率仍有 25%。

## ③ 自校验 / 质检（规则 v1c）

```
QC = max( 轨迹 vs ViPE / 3.27% ,  深度 vs DA3(用 ViPE 相机) / 0.194 ,  K 分歧 / 13.2° )
QC > 1  → 整段拒绝
```

另有旗标（不计分，供人工复核）：K 门控触发、视角跳变 > 60°、HFOV 不在 [30°, 120°]、相机静止（焦距不可观）、旋转跳变 > 20°（疑似切镜）、焦距变化 > 7%（疑似变焦）。

效果：v1.3 标签保留 75%，留下的失败率 5.8%；C 组野外拒绝 54%。跨模型核对找坏标签的 AUROC 0.91–0.94，单模型自检（重投影 / Sampson）最高 0.84；再加一道重投影几何关没有收益（E13）。

## ④ 人工抽检

复核页按 QC 分数从高到低列出 C 组片段；人工结论用来校准 ③ 的阈值（目前阈值只在 64 段有真值片段上定）。
